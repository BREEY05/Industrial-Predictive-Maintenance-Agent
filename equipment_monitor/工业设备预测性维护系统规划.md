# 基于本地大模型的轻量化工业设备预测性维护系统

## 📋 项目概览

**项目名称**：工业设备预测性维护智能体系统  
**项目阶段**：原型开发（MVP）  
**预计工期**：2-3周

---

## 🎯 项目目标

### 核心功能
1. ✅ 树莓派数据采集端：键盘模拟输入 → Excel存储 → API服务
2. ✅ 电脑智能分析端：定期API调用 → 异常检测 → Ollama分析 → 飞书告警
3. ✅ Web可视化界面：实时设备状态展示
4. ✅ 消息推送：飞书机器人实时告警

- `GET /api/set_ollama` - 设置 Ollama IP。
- `GET /` - Web 仪表盘页面。

**Web仪表盘功能**：
- 实时设备状态显示。
- 异常记录列表。
- 自动刷新（1秒）。

### 电脑端关键点

#### 1. 配置管理 (config.py)
```python
# 全局配置项

```

#### 2. 智能体主循环 (agent_main.py)
```python
from . import config
from .anomaly_detector import AnomalyDetector
from .ollama_analyzer import OllamaAnalyzer
from .feishu_notifier import FeishuNotifier
from ..raspberry import data_simulator # 导入树莓派端的 data_simulator

class AgentMain:
    def __init__(self, raspberry_pi_ip: str):
        self.anomaly_detector = AnomalyDetector(raspberry_pi_ip)
        self.ollama_analyzer = OllamaAnalyzer()
        self.feishu_notifier = FeishuNotifier()

    async def run_analysis_loop(self):
        while True:
            if data_simulator.auto_submit_signal.is_set():
                await self.perform_analysis(auto=True)
                data_simulator.reset_auto_submitting_flag()
            await asyncio.sleep(config.MONITOR_INTERVAL)

    async def perform_analysis(self, auto: bool = False):
        records, analyzed_count, anomaly_count = data_simulator.get_pending_records_for_analysis()
        if records:
            analysis_result = await self.ollama_analyzer.analyze_data(records, auto=auto)
            if analysis_result["status"] == "ok":
                feishu_status = await self.feishu_notifier.send_feishu_notification(analysis_result)
                data_simulator.save_submit_log(analysis_result, feishu_status, config.RASPBERRY_PI_SUBMIT_LOG_PATH)
                data_simulator.add_auto_result_for_frontend(analysis_result)
```
