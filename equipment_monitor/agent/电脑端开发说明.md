## 🚀 快速开始

### 第一步：启动 Ollama 服务

在新的终端窗口中运行：
```bash
ollama serve
```

或者检查 Ollama 是否已经在运行：
```bash
ollama list
```

如果没有 `qwen3:4b` 模型，先拉取：
```bash
ollama pull qwen3:4b
```

### 第二步：测试 Ollama 连接

在 `equipment_monitor/agent` 目录下运行：
```bash
python test_ollama.py
```

**预期结果：**
- ✅ 显示连接成功
- ✅ AI 回复一条问候消息

### 第三步：运行本地测试版智能体

- 30% 概率生成异常数据用于测试

## 🔧 配置说明

编辑 `.env` 文件可以修改配置：

```env
RASPBERRY_PI_IP=192.168.1.100    # 树莓派IP（完整版用）
FEISHU_WEBHOOK=your_webhook_url    # 飞书Webhook
MONITOR_INTERVAL=10                 # 监控间隔（秒），测试时可以改小
OLLAMA_MODEL=qwen3:4b               # Ollama模型
OLLAMA_BASE_URL=http://localhost:11434
```

**提示：** 测试时可以把 `MONITOR_INTERVAL` 改成 5 或 10，加快测试速度。
